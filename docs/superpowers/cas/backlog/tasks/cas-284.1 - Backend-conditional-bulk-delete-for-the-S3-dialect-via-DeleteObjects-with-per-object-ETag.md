## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a backend operation that deletes up to 1000 keys with one exact token each through `DeleteObjectsRequest` (`src/IO/S3/Requests.h:220`) setting `ObjectIdentifier::SetETag`; map each `<Deleted>` / `<Error>` entry to the existing `ConditionalRemoveOutcome` (Removed, TokenMismatch on the precondition error code, NotFound). Malformed tokens (empty, wildcard, list) are refused as today (`CasObjectStorageBackend.cpp:953`). Delete-marker creation must be reported per object as the single-key path does.
