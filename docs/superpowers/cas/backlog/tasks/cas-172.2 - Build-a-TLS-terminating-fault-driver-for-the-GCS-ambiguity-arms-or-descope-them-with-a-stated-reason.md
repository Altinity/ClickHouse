## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Four ambiguity cases (`CAS_HMAC_AMBIGUITY_DISK`, `CAS_OAUTH_AMBIGUITY_DISK` in `test_gcs_live/test.py`) need a driver that cuts the TLS connection after Google accepted the request.
The existing proxies (`utils/ca-soak/proxy/s3_fault_proxy.py`, `tests/integration/test_cas_mount_renewal_retry/s3_fault_proxy.py`) are plain HTTP and cannot front `storage.googleapis.com`.
Decision first: build the driver (days) or descope the four arms, since the same ambiguity is covered against fake GCS and RustFS.
