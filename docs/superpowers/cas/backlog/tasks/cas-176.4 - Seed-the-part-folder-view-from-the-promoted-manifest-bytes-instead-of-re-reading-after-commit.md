## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`CachedPartFolderAccess::promoteBuild` invalidates the view after the commit (`eraseView`, `R/Parts/PartFolderAccess.cpp:297-329`).
The part loader then rebuilds it through `getSkipIndicesPackedReader`, `existsFile`, `getView` and `readManifestShared`: one more manifest GET per publish (audit F9, F30).
decision-5: seed the view from the manifest bytes already in memory.
Mind the allocation rule of the commit-recorded region (`CAS-113`): seeding must not add a throwing step before the commit is recorded.

Provenance: BACKLOG/ref-protocol.md#part-publish-zero-gets item 4. Verified 2026-09-26 against b1c34d03479 and 0dbbd797792.
<!-- SECTION:DESCRIPTION:END -->
