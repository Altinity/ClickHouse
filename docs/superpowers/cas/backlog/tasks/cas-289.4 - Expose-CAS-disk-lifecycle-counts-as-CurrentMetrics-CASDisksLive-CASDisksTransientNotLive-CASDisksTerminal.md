## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
No gauge records whether a CAS disk is Live; only event counters (CASMountLeaseLost, CASRemount*) exist, so a dashboard cannot show when a host was not live. Add three CurrentMetrics maintained at the PoolLifecycle transitions in Pool/CasMountRuntime.h: disks in Live, in TransientNotLive, in a terminal state (IdentityLost, VanishedReplaced, VanishedForgotten). CurrentMetrics, not asynchronous metrics: the value is exact at the transition and costs nothing to keep (user decision 2026-09-30). Blocks CAS-289.3.
