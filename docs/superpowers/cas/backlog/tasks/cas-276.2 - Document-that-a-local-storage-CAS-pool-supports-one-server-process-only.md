## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Nothing under `docs/en/antalya/cas/` says that a CAS disk with `object_storage_type = local` is single-process: put-if-absent
is racy across processes and hosts, so NFS or shared mounts by several servers are unsafe, and mutable control objects are not
atomically visible (`[B66a]`). Operators can configure it today without a warning.

Provenance: BACKLOG/formats-and-storage.md [B26 / B135]; verified 2026-09-26 against 8b87aa15d21 (cas-gc-rebuild).
