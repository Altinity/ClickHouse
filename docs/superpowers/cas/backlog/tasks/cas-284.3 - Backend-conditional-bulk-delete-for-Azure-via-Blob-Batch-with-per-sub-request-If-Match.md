## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Azure Blob Batch (up to 256 sub-requests, non-atomic) carries `If-Match` per `Delete Blob` sub-request; the SDK shortcut `DeleteBlobsAsync(IEnumerable<Uri>)` takes no conditions, so the batch must be assembled from per-blob `DeleteBlob(uri, snapshots, conditions)`. Depends on the Azure backend existing at all (CAS on Azure task).
