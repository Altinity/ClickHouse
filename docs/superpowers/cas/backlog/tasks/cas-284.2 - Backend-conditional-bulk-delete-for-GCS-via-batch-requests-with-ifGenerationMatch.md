## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
GCS has no `DeleteObjects`; the batch endpoint takes a multipart/mixed body of nested JSON-API requests, each `DELETE .../o/<name>?ifGenerationMatch=<generation>` (about 100 sub-requests per batch), processed independently. The GCS dialect currently falls back to one admitted delete per key (`CA/Gc/CasGc.cpp:1132`). Add the batch transport to the GCS conditional dialect (`src/IO/S3/GCSConditionalDialect.*`) or a sibling, parse per-sub-request status, and keep the generation as the token.
<!-- SECTION:DESCRIPTION:END -->
