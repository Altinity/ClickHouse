## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`cas-drop-member` refuses while the victim's lease is alive, so S45 waits for it to lapse; during that wait the survivor, as GC leader,
retires every `Removing` namespace pool-wide. The tool then reports `namespaces_removed=0` deterministically, and the verdict was rewritten
to "no victim rows survive" (`s45_decommission_hidden_removing.py:231-247`). The tool's own sweep path has no coverage at all.
With `cas_gc_enabled` off on the survivor the rows persist and only the tool can remove them.

Provenance: BACKLOG/testing-and-ci.md#s45-drop-member-sweep-untested; verified 2026-09-26 against 8b87aa15d21.
