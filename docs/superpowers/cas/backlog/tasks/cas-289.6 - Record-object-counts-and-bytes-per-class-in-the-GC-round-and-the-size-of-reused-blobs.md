## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The pool inventory panels (utils/cas-grafana, row 'GC: pool inventory') can show namespaces, live refs and ref keys from phase_metrics, but no surface records how many blobs or manifests the pool holds, nor bytes per object class; only flows (CASBlobHeadMiss, CASBlobDelete, blob_storage_log uploads) exist, so the boards show change, not population. Also cas_log blob_reuse_adopt rows record size 0 for the adopt action (only observed rows carry a size), so bytes saved by deduplication cannot be summed. Add to the round seal or a Finish-row map: objects and bytes per class (blobs, manifests, ref logs, snapshots and checkpoints, gc state) as the fold sees them, and record the blob size in every blob_reuse_adopt row. Extends CAS-11 (bytes in fsck and per round) to counts and to a per-round surface the dashboards can read.
