## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The roadmap's alert set: lease lost, renewal retries, GC round age, backlog growth, conditional-write unresolved rate, S3 5xx.
Not on `S3ReadRequestsErrors`, which counts protocol 404s (audit F10, F25).
CAS-4 maps each signal onto an existing surface. Two inputs are wrong today: `CASGCLastSuccessAgeSeconds` reads 0 when no round ever
succeeded (CAS-1.1) and `pending_reclaim` goes negative after a restart (CAS-1.3), so round-age and backlog alerts wait for those fixes.

Provenance: umbrella-roadmap.md section 3 bullets 'Grafana dashboard' and 'Alerts' (the latter owned by CAS-4); filed 2026-09-26 (user decision). Verified 2026-09-26 against c16a2589f56 (cas-gc-rebuild) and 8d62c314ec1 (altinity/antalya-26.6).
