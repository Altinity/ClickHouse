## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Rows from audit F25: ref lane (`CASRefQueueWaitMicroseconds` as a rate over minutes, `CASRefBatchedMutations / CASRefBatchFlushes`,
`CASRefBatchFlushes` per second), write safety (`CASConditionalWriteAttempts`, `Committed`, `Unresolved`, `CASRequestResolveRead`),
GC stage flow (`CASGCRetiredCondemned`, `Graduated`, `Redeleted` and their cumulative differences), cleanup balance
(`CASRootPut` against `CASRefCleanupObjectsDeleted`), fold read-ahead, mounts (`CASMountRenewalAttempts`, `Retries`, `Recovered`,
`CASMountLeaseLost`), `S3ListObjects` per second, `MemoryTracking`, S3 throttling.
Leave out the `_cas_cache` copies of `CASGC*` metrics (they double every sum) and the 99 counters that never moved.
