## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Five refusal events exist (`src/Common/ProfileEvents.cpp:817-821`): `RefMutationInFlight`, `LaneWedged`, `LaneBroken`, `StateLockBusy`, `MountCannotSpeak`; the `RefTableNotResident` event of PR #2364 was never merged (PR closed 2026-09-16).
Proposal: `RefMutationInFlight` + `StateLockBusy` into one `Busy` (same action: retry); `LaneWedged` + `LaneBroken` into one `LaneUnavailable` (the split is already in the `refuse` trace line in `confirmExactRef`, `Pool/CasRefLedger.cpp:470-476`); keep `MountCannotSpeak`.
`StateLockBusy` has no test and no seam for one (`CasRefLedger.cpp:487`); merging removes the untested name.
Do not add counters for the `Unknown` returns above the ledger (`resolveContentAddressedConfirm` in `DataPartsExchange.cpp`): they are misconfiguration or protocol errors, and `answerContentAddressedConfirm` already logs every non-`Yes` at Debug (`:308`).
Rename once, after the gate run, so the spec, integration test and issue text change once. Fits the event rule of CAS-2.

Provenance: BACKLOG/gcs.md#relink-confirm-lane-livelock checklist item 3 and 'StateLockBusy is exercised by no test'. Related: CAS-2 (ProfileEvents audit, names this item as owned here), CAS-123 (receiver-side outcomes). Verified 2026-09-26 against 8b87aa15d21 and 8d62c314ec1.
